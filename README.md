# What is the bundle archiver?
The bundle archiver was made to easily .zip up and send your bundles to your friends, which stops them from having to download them in the client which can be slow.

# How do I use it?
1. Place it in your SPT installation folder (very important that it's next to your `EscapeFromTarkov.exe`)
2. Run the tool (if something is wrong, it will tell you)
3. Click `Scan` to scan for all mods with bundles
4. If you want to, enable high compression to reduce file size, but the archiving process will be slower
5. Click `Start` and wait
6. Send the output file 'ArchivedBundles.zip' (it will be placed in the same folder as `EscapeFromTarkov.exe`) to your friends
7. Have them extract it to their own SPT installation folder
